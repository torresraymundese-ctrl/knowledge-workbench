# 文件查看与资料地图复核增强设计

## 1. 目标

本次改造解决四个直接影响使用者理解资料的问题：

1. 资料库中的正式资料可以点击，并由本机对应程序打开只读副本。
2. DeepSeek 已绑定时默认参与知识问答；使用者仍可在发送前取消。
3. 全库资料地图的五张统计卡可以点击，直接查看对应文件。
4. 文档说明卡提供足够的正文节选和关联文件信息，使范围、权威性与版本判断不再只依赖字数和文件名。

本次不改变问答检索算法、不增加云端文档解析、不自动替使用者作范围或权威性决定。

## 2. 用户体验

### 2.1 资料库打开正式资料

- 资料名称显示为明确可点击的按钮或链接，并带“用本机应用打开”的可访问名称。
- 点击后，浏览器向本机工作台发送受控打开请求。
- 工作台只允许打开当前文档版本在 `workspace/raw/` 中的只读副本。
- Windows 使用文件类型关联的本机程序打开文件，例如 Word、Excel、PowerPoint 或 PDF 阅读器。
- 页面显示“已用本机应用打开只读副本”的成功提示。
- `restricted` 资料、缺失文件、不是当前版本的文件或越出 `workspace/raw/` 的路径一律拒绝。
- 服务端不把绝对路径或 `stored_path` 返回给浏览器。

### 2.2 DeepSeek 默认参与

- `/api/v1/bootstrap` 表明 DeepSeek 已配置时，复选框默认为勾选。
- 提交问题后仍恢复为勾选状态；刷新页面后也默认为勾选。
- 使用者取消勾选时，仅当前问题走本地回答；问题提交完成后恢复默认勾选。
- 提示文字改为：
  - 已绑定：`已绑定；默认用于每次提问，可在发送前取消。本次提交会记录云调用审计。`
  - 未绑定：维持当前“只能使用本地摘录回答”的说明。
- 后端继续以每次请求中的 `allow_deepseek_once` 为唯一授权信号；服务端不创建永久云授权开关。
- 每次发送按钮点击仍是一次明确提交动作，现有密级策略、模型输出校验和审计保持不变。

### 2.3 资料地图统计卡

五张统计卡改为按钮，并具有选中状态：

| 卡片 | 筛选语义 |
|---|---|
| 发现文件 | 当前扫描中的全部文件，并清除统计卡筛选 |
| 已读懂正文 | `map_status = readable` |
| 重复文件组 | `duplicate_group IS NOT NULL` |
| 版本候选组 | `version_group IS NOT NULL` |
| 需要关注 | `map_status IN ('blocked', 'unreadable')` |

- 选择统计卡后将当前页码归零，通过服务端查询完整结果，不能只过滤当前已经加载的 12 条。
- 当前统计卡以薄荷绿色边框和浅色背景标识，并显示对应筛选说明。
- 文件夹、范围状态和关键词筛选与统计卡筛选可以叠加。
- 点击“发现文件”恢复全部；清除筛选同时恢复“发现文件”。
- 查询参数使用稳定的 `view` 值：`all`、`readable`、`duplicates`、`versions`、`attention`。
- 服务端拒绝未知 `view`，避免把任意 SQL 条件暴露给浏览器。

### 2.4 文档说明卡增强

说明卡按照使用者判断顺序重新组织：

1. **这份资料主要讲什么**
   - 保留现有普通文字摘要。
   - 显示文件类型、所在目录、读取状态和大小。

2. **代表性正文节选**
   - 扫描阶段在本机从解析单元生成预览，不调用模型。
   - 最多保存 8 个预览片段。
   - 每个片段包含可读标题或位置说明，以及最多 360 个字符的正文。
   - 总预览正文不超过 2,400 个字符。
   - 优先覆盖不同标题、工作表、PDF 页面或幻灯片，避免全部片段都来自文件开头。
   - 没有结构定位时，均匀选择文档开头、中部和结尾附近的代表性单元。
   - 账号密码、密钥类风险文件仍只保存安全元数据，不生成正文预览。

3. **文档结构**
   - 显示现有标题目录、工作表、页码范围或幻灯片范围。

4. **与其他文件的关系**
   - 重复文件和版本候选以关系卡展示，不再只是普通列表文字。
   - 每张关系卡显示对方文件名称、关系原因和“查看对方说明”按钮。
   - 点击后在同一说明对话框加载对方文档，方便连续比较。
   - 如果没有系统候选关系，明确说明系统只检查了“内容完全相同”和“文件名疑似版本”两类关系，不能据此断定业务无关。

5. **范围与权威性判断**
   - 判断表单保持在内容与关系信息之后。
   - 增加提示：范围表示是否属于当前知识库，权威性表示能否作为现行主要依据，两者不是同一判断。
   - 已导入状态、风险阻断和导入操作继续复用现有规则。

## 3. 数据结构

SQLite Schema 从版本 17 升级到版本 18。

`corpus_files` 新增：

```sql
content_preview_json TEXT NOT NULL DEFAULT '[]'
    CHECK (
        json_valid(content_preview_json)
        AND json_type(content_preview_json) = 'array'
    )
```

预览项的稳定结构：

```json
{
  "label": "第 3 页 · 5.2 安全要求",
  "text": "报名和组团时，应对旅游线路和旅游项目风险等安全事宜做出明示……"
}
```

约束：

- `label` 和 `text` 均由本机解析结果生成。
- `text` 必须去除空白噪声且非空。
- 投影到 Web 前再次限制单项和总长度。
- 旧扫描记录迁移后预览为空；用户重新扫描时生成完整预览。

不把原始绝对路径、只读副本路径或完整解析正文加入 Web JSON。

## 4. 服务端接口

### 4.1 打开只读副本

新增：

```text
POST /api/v1/documents/{document_id}/open
```

请求：

```json
{"actor": "ZZ"}
```

响应：

```json
{
  "ok": true,
  "result": {
    "document_id": "doc_...",
    "opened": true,
    "display_name": "资料名称.docx"
  }
}
```

服务端处理顺序：

1. 校验 CSRF、Origin、actor 和文档 ID。
2. 查询当前文档版本与密级。
3. 拒绝 `restricted`。
4. 解析 `stored_path`，确认最终路径位于 `WorkspacePaths.raw` 内。
5. 确认文件存在，并再次确认不是目录。
6. 在 Windows 调用受控的系统文件打开函数。
7. 写入不含路径的 `document_opened_locally` 审计事件。

系统打开失败时返回普通中文错误，不回显命令、绝对路径或操作系统内部异常。

### 4.2 资料地图筛选

扩展：

```text
GET /api/v1/corpus-map?view=all|readable|duplicates|versions|attention
```

`WorkbenchReadService.corpus_map()` 和 `latest_corpus_map()` 增加 `view` 参数。所有筛选继续由参数化 SQL 完成。

### 4.3 文档说明卡

现有接口保持不变：

```text
GET /api/v1/corpus-files/{file_id}
```

响应新增 `content_preview` 数组。风险文件始终返回空数组。

## 5. 模块边界

- `corpus_map.py`
  - 负责从解析单元生成安全预览。
  - 负责资料地图 `view` 筛选与说明卡投影。
- `web_service.py`
  - 负责正式资料只读副本的查询、路径约束和本机打开动作。
  - 不向前端返回文件路径。
- `webapp.py`
  - 负责新增 POST 路由、CSRF/Origin 校验和错误映射。
- `web_assets/app.js`
  - 负责资料名称点击、DeepSeek 默认勾选、统计卡选中与说明卡的预览/关系交互。
- `web_assets/index.html`
  - 负责说明卡新增的语义化内容容器和判断提示。
- `web_assets/app.css`
  - 负责可点击资料名、统计卡选中态、正文预览块与关系卡样式。

不在本次工作中拆分现有大型 `app.js`，避免引入与目标无关的重构。

## 6. 错误处理与安全

- 本机打开操作只接受数据库中的 `document_id`，不接受浏览器提交路径。
- 路径必须在解析后位于 `workspace/raw/`；符号链接或路径跳转导致越界时拒绝。
- `restricted` 文档的名称仍可按现有规则脱敏，但不能打开。
- 资料地图中的疑似凭据文件不生成正文节选，不显示真实路径，不允许纳入范围。
- 正文预览只在明确发起本机扫描时生成，不调用 DeepSeek。
- DeepSeek 默认勾选不绕过后端密级规则；`confidential` 和 `restricted` 仍禁止发送。
- 文件打不开、关联文件已失效或旧扫描没有预览时，界面给出可恢复的普通中文提示。

## 7. 测试策略

所有生产代码修改遵循测试先行。

### 数据库与资料地图

- 版本 17 数据库可以幂等迁移到版本 18。
- 新扫描为普通资料生成有上限的 `content_preview_json`。
- 风险文件的预览始终为空。
- `view` 五种值返回正确文件集合，未知值返回错误。
- 说明卡只返回受控预览字段和已有文件关系。

### 文件打开

- 当前非受限资料可以打开 `workspace/raw/` 内的当前版本。
- `restricted`、不存在文件、旧版本和越界路径被拒绝。
- Web 响应和审计不包含绝对路径。
- 路由要求 POST、CSRF、Origin 和 actor。
- 测试注入文件打开函数，避免测试过程中真的启动 Word 或 PDF 阅读器。

### 前端

- DeepSeek 已配置时默认勾选，提交完成与清空对话后仍恢复勾选。
- 未配置时复选框禁用且不勾选。
- 资料行包含可点击打开控件。
- 五张统计卡具有稳定 `data-corpus-view` 属性与选中态。
- 说明卡能渲染正文预览及可点击的关联文件。

### 回归验证

- 完整 Python 测试通过。
- JavaScript 语法检查通过。
- Lint 为 0 错误、0 警告。
- 浏览器验证资料库打开按钮、五类统计筛选、关联说明跳转、DeepSeek 默认勾选和窄屏布局。
- 浏览器控制台无 error 或 warning。

## 8. 验收标准

- 使用者能从资料库点击正式资料，并在本机对应程序中打开只读副本。
- DeepSeek 已绑定时，每次进入或完成问答后均默认勾选，用户可在发送前取消。
- 五张资料地图统计卡均可点击，并能展示全库范围内的正确结果。
- 基准资料说明卡至少展示摘要、代表性正文、结构和系统发现的关联文件。
- 使用者可以从一个说明卡继续查看关联文件，再进行范围和权威性判断。
- 所有新增读取能力不暴露绝对路径，不开放风险或受限内容，不调用云模型解析文件。
